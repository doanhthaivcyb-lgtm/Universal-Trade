Key AI và an toàn

Đang kiểm tra...

Giao diện chỉ hiện có hay chưa có key, không bao giờ hiện giá trị key. Muốn điền key, mở file .env bằng Notepad trên máy Windows, không dán key vào đây hay vào chat.

Chế độ live bị khóa trên giao diện web. Muốn bật live vẫn phải sửa tay config.yaml và .env, và giao diện sẽ từ chối chạy nếu live đã bật.
